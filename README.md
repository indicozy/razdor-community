# Razdor — карты и моды сообщества

Здесь лежат карты, кампании и моды сообщества «Времён раздора», собранные для окна
«Карты и моды» в [Razdor](https://github.com/indicozy/razdor). Скачивать отсюда руками не нужно:
игра сама берёт каталог из последнего выпуска (`index.json` и файлы рядом с ним).

- Карты и моды взяты с сервера Discord сообщества (форумы «сокровищница-модов» и
  «библиотека-карт») с разрешения администрации сервера. У каждой записи в каталоге указаны автор
  и ссылка на её тему; все права на карты и моды — у их авторов.
- Моды хранятся только как отличия от Community Update: файлов самой игры здесь нет, для игры
  нужна своя копия «Времён раздора».
- Музыка и звуки модов пережаты в Ogg Vorbis, чтобы скачивание было меньше; Razdor играет их
  вместо исходных файлов.

Автор хочет убрать свою работу или поправить описание? Напишите в Discord или откройте issue.
